
# pyseries

**A progression of Python projects, from fundamentals to advanced applications.**

`pyseries` is a collection of Python projects developed throughout my journey of learning Python. Each project represents a step forward in understanding the language, exploring its ecosystem, and applying concepts to practical problems.

The repository will evolve alongside my learning. Projects may cover different areas of software development, with a potential focus on **Machine Learning, data-oriented applications, and practical AI-related engineering**.

Rather than following a fixed curriculum, the progression will be driven by experimentation, increasing complexity, and the problems I want to solve.

## Progression

Projects are organized into levels based on their complexity and the concepts they introduce.

| Level | Focus | Description |
|---|---|---|
| 01 | Fundamentals | Python syntax, data structures, functions, OOP and basic problem solving. |
| 02 | Intermediate | Modules, file handling, exceptions, APIs, databases and external libraries. |
| 03 | Applied Python | Practical applications, automation, data processing and scripting. |
| 04 | Advanced | Architecture, concurrency, performance, testing and complex applications. |
| 05 | Specialized | Machine Learning, data science, AI infrastructure and other specialized domains. |

## Philosophy

- **Learn by building:** Apply concepts through actual projects rather than isolated exercises.
- **Progressive complexity:** Gradually move from simple implementations to more complex systems.
- **Explore broadly:** Experiment with different areas of Python before narrowing down specializations.
- **Understand the internals:** Focus on understanding why something works, not just how to use a library.
- **Iterate:** Revisit and improve earlier implementations as knowledge develops.
